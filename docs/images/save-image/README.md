# Screenshots — Visual Save Image

Two shots, both at the same node width so they sit together on the page. Use a
render you are happy with; a placeholder undersells what the node is for.

The overlay text is set beside each shot, in the pack's house style: a short
title in caps, one line under it.

---

## `01-overview.png`

**VISUAL SAVE IMAGE**
Saves what you rendered, and keeps the folder within reach.

**MORE THAN SAVING**
A few things the default node leaves out — copies beside the PNG, the folder a
click away, the render before this one

Full node, top to bottom: the settings on one line, the picture filling the
rest, the file just written named underneath. Leave the node wide enough that
the file name is not wrapped — its length is part of the argument. Turn `jpg`
on so one toggle is lit and the `quality` field is live rather than greyed.

Used twice: here and as the hero shot in the main README.
